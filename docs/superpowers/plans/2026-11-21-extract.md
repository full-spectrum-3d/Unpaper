# Ekstrakcja (krok [3]) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `extract(NormalizedDocument, Settings) -> ExtractionResult` zamienia PDF/DOCX/XLSX/JPEG/PNG na `DocumentModel` z blokami pól, opcji, nagłówków i tabel.

**Architecture:** Każdy format daje elementy z geometrią (`Span`, `Frame`, `TableGrid`), a wspólny `layout.py` składa je w linie i bloki. Akapity i tabele DOCX bez geometrii idą bezpośrednio do `DocumentBuilder`, korzystając z tych samych `text_rules`. OCR za protokołem `OcrEngine` (Tesseract w produkcji, atrapa w testach).

**Tech Stack:** Python 3.14, pdfplumber, pypdfium2, python-docx (lxml), openpyxl, Pillow, pytesseract, pytest.

**Spec:** `docs/superpowers/specs/2026-11-21-extract-design.md` (+ `docs/specyfikacja-techniczna.md` §5.3)

## Global Constraints

- Bez nowych zależności (wszystko jest w `pyproject.toml`); bez GPL/AGPL (nie PyMuPDF).
- `ruff check` i `mypy --strict` czyste; linia ≤ 100 znaków; komentarze i komunikaty po polsku.
- Każde wywołanie pypdfium2 pod `app.pipeline.pdfium_lock.PDFIUM_LOCK`.
- Ostrzeżenia jako `ConversionWarning` z kodem `Wnn_NAZWA`; treść dokumentu nie trafia do logów ani do `detail` błędów.
- Nie zmieniać `app/models/document.py` (kontrakt z `analyze`).
- Współrzędne w punktach, `y` rośnie w dół (konwencja `top`/`bottom` pdfplumber).

## Review Focus

1. Tekst z DOCX z polami tekstowymi nie może pojawić się dwa razy (`mc:Choice` + `mc:Fallback`) – test `test_textbox_alternate_content_not_duplicated` (Task 3).
2. Uszkodzony plik, który przeszedł walidację, daje 422 `DOCUMENT_UNREADABLE`, nie 500 – test `test_corrupt_file_is_unreadable` (Task 7).
3. PDF o bardzo dużym formacie strony nie rasteryzuje się powyżej `MAX_IMAGE_PIXELS` – test `test_render_scale_capped` (Task 6).
4. Brak Tesseracta nie przerywa żądania: pusta strona + `W11_OCR_UNAVAILABLE` – test `test_ocr_unavailable_warns` (Task 7).
5. Kratki NIP (ciąg pustych ramek) dają jedno pole, nie dziesięć – test `test_adjacent_frames_merge` (Task 2).
